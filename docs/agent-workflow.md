# Agent visual feedback workflow

The canonical workflow is now the self-contained, installable
[`elle-snapshot` skill](../skills/elle-snapshot/SKILL.md). It covers browser capture,
PNG/Figma references, explicit asset selection, visual inspection, iteration,
reporting, and the tool's limitations.

See [Install the agent skill](../README.md#install-the-agent-skill) for installation.
The skill supplies instructions, not the CLI or browser dependencies. It can also
be read directly by an agent without installing it.
